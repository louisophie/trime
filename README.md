## Why I design a keyboard in Trime for my bloodsugar log:

I've used Multiling O Keyboard in Android for quite a time. It provides a awesome framework for personal keyboard design and setting, thus a great tool for my bloodsugar logging. For this period, I have added and modified shortcuts, key-combinations and various icons by demand on it. I have had really a good time by using this incredible android app in my health improving.

However, some issues happen when my old android phone is replaced by an android16 system: MOK's bottom bar would be overlapped by OS's gesture insets, and its Chinese input would make it freezed and reset because of priority fighting. Moreover, it is a sad thing that MOK has not been updated since Jan 31, 2025 in google's playstore, and I has no idea how to fix these issues without its opensource.

Luckily, there is opensourced Trime in which I am quite familiar with its core Rime, for that I have used ibus then fcitx with it for years. As a result, this tongwen-T1D keyboard in Trime is created.

By my original MOK's keyboard arrangment, this tongwen-T1D keyboard has more features due to its usage on tmux, micro and cli-agents (Opencode and ClaudeCode) in Termux. There are still many issues, and I will do as much as I can to improve this keyboard setting with my bloodsugar logging.
